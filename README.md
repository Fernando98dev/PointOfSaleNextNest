## Backend Project setup(posnest)

First rename the .env.template to .env and complete the backend environment
variables.

```bash
$ npm install
```

## Compile and run the backend project

```bash
$ docker compose up -d

#provision the database
$ npm run seed
# watch mode
$ npm run start:dev
